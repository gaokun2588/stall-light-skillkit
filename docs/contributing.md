# 如何贡献

欢迎通过 Issue 或 Pull Request 提交具体失败案例和修正方法。优先提供：

1. 目标与允许改变的范围。
2. 可公开的参考素材及来源、使用范围。
3. 工具与已知版本、实际提示词、可记录的生成设置。
4. 修改前后结果、哪些因素同时改变。
5. 按验收表给出的通过、失败与未知项。

不要提交个人联系方式、聊天截图、顾客身份信息、凭据或不明来源素材。保留 AI 标记，区分实拍、生成与后期合成。不把未验证的经验写成平台规则或收益保证。

文档与提示词贡献沿用 MIT；图片须单独写明授权范围，不能默认与文字同授权。保持相对链接，新增规则需有明确适用条件，避免为单个失败不断增加全局硬规则。
