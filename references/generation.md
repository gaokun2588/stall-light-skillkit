# AI 图像与分镜工作流

## 1. 写事实卡

记录食物名称、可见颜色与形态、容器、穿签方式、真实品牌文字，以及允许改变的部分。看不清或未提供的项保持未知。

“允许改善光线”不等于允许增加食材、堆高份量、改变菜品或补写工艺宣称。

## 2. 选择方式

| 任务 | 起始方式 | 主要限制 |
|---|---|---|
| 保留真实产品，改善可见度 | 曝光、白平衡、裁切等常规编辑 | 无法恢复原片没有的细节 |
| 借实拍探索氛围 | 参考图生成或局部修改 | 仍可能改变产品，逐项验收 |
| 没有照片，探索构图 | 文生图概念稿 | 不能声称符合真实产品 |
| 价格、菜单、精确招牌 | 图片底图加独立文字排版 | 按真实信息校字 |
| 连续镜头 | 通过验收的首帧再制作动态 | 首帧正确不代表中途没有变形 |

对话式工具：上传参考图，明确保留项和修改项。节点式工具：另外记录模型、参考控制方式、采样和输出设置。只记录工具实际支持的字段，不假定都有负面提示词或随机种子。历史参数不补猜。

## 3. 可替换提示词

以下是整理后的模板，不是历史案例的逐字生成记录。

```text
目标：用于【食物展示/过程/环境/品牌】的【画幅】画面。
参考图中的【主体】是产品基准，保留【颜色、形态、穿签方式、容器】。
本次仅调整【允许改变的区域或表现】。
主体位于【位置】，呈现【真实可成立的动作】，焦点落在【具体部位】。
光从【方向】照来，亮部保留纹理，食物颜色以参考为准。
背景【描述】，避免抢主体。
不要增加未确认食材、改变分量或继承无关店名与个人信息。
文字仅为【用户确认内容】；不需要文字时输出无字底图。
```

没有参考图时，去掉“保留参考”的表述，明确是概念稿。

## 4. 分镜先分工

15 秒可从“环境 3 秒 → 过程 4 秒 → 产品特写 5 秒 → 信息收尾 3 秒”起步，按素材调整。每个生成镜头尽量一个主要动作；这是便于控制的起点，不是平台限制。

动态提示词写清谁在动、方向、幅度、运镜、哪些元素稳定。不要同时要求快速推近、旋转、焦点切换和复杂手部动作。

## 5. 返工顺序

先修产品事实，再修空间与文字，最后调风格。一次重点修一个问题，保留上一版比较。多个因素同时变化时，只作为探索记录，不能声称某一句提示词独立导致改进。

图生图后仍执行 [验收表](quality-check.md)。历史案例见 [颜色校准](../examples/01-color-calibration.md) 与 [空间关系](../examples/02-spatial-continuity.md)。
