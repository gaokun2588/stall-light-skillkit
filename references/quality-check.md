# 交付验收

每项标为“通过 / 失败 / 未知 / 不适用”。关键事实失败时返工；未知时说明限制，不标为已校准。

| 检查项 | 看什么 |
|---|---|
| 产品身份 | 食材是否一致，有无新增配料、素菜变肉串 |
| 外观 | 颜色、形状、纹理、数量与大小是否偏离参考 |
| 连接 | 手是否握住工具，签是否穿在食物上，提起和滴落方向是否成立 |
| 容器 | 材质、形状、罐口与食物的空间关系 |
| 文字 | 店名、价格逐字核对，无关招牌、电话、二维码有无混入 |
| 画面 | 焦点清楚，亮部有细节，背景不抢主体，热气不遮挡 |
| 事实表达 | 不以生成画面证明销量、排队、工艺、卫生或顾客评价 |
| 来源 | 实拍与生成标清，素材来源和公开使用范围已记录 |

## 视频追加

检查首尾及动作关键位置，全程播放检查物体漂移、文字变形、食材变化、闪烁和音画关系。抽帧用于记录，不能宣布未看过的帧全部合格。高要求文字素材进一步逐帧检查，或后期叠加稳定文字层。

## 报告示例

> 颜色接近参考，手持动作比上一版清楚。鸡爪与竹签接触处需放大确认；新增配料未获得事实支持。适合作为风格探索，暂不作为真实产品图交付。下一步先移除新增配料，再复核连接关系。

对比照片展示视觉差异，不能把单次主观选择写成 A/B 实验胜出或转化提升。
