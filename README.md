# 摊店光影 · Stall Light

从真实地摊素材出发，设计拍摄与 AI 视觉方案，并检查食材、空间关系和招牌文字是否跑偏。

这是一套从瓦罐串串项目整理出的中文技能包，适合摊主、内容创作者，以及能够读取 Markdown 和参考图片的 AI 助手。

**项目已经产出图片与视频素材，但尚未验证经济收益。** 这里分享制作方法、失败版本和修正过程，不承诺播放量、到店数或收入。

## 怎么使用

直接阅读：从 [拍摄参考](references/shooting.md) 或 [AI 提示词与修正流程](references/generation.md) 开始，交付前按 [验收表](references/quality-check.md) 检查。

交给 AI：将 [SKILL.md](SKILL.md) 和本次需要的参考文件交给支持文件阅读的助手，并上传自己的食物照片。例如：

> 使用摊店光影方法，帮我规划一条 15 秒的卤味短视频。我有摊位全景和鸡爪近照，希望保留真实颜色。先输出镜头表、缺少的素材和提示词，不生成图片。

普通聊天工具不会因为文件名叫 SKILL.md 就自动执行它，需要明确提供内容和图片。支持目录式技能包的客户端，可按其导入流程将本目录作为 `stall-light` 导入，保留全部参考文件。

需要夜市红油卤味风时，再使用 [风格预设](presets/red-oil-night-market.md)。它不是所有食物的统一配方。

## 输入与输出

输入：用途、食物品类、参考照片、允许改变的部分、画幅；如有真实品牌信息，另行提供。

输出：任务分支、事实与未知项、镜头或图片方案、提示词、验收结果及下一步修改。缺少实拍时可以做概念探索，不能声称产品形态已经校准。

不绑定生图接口，不包含付费调用、自动上传或平台发布脚本。没有生成工具时仍可输出拍摄方案与可复制提示词。

## 验证范围

- 案例来源于一个瓦罐串串项目，不代表跨品类效果。
- 原项目包含豆包相关素材与其他工具产物；图片原有标记保留，未把全部产物归为豆包生成。
- 部分历史记录缺少模型版本、随机种子和界面参数，不保证逐像素复现。
- 本次整理未重新调用生成模型，也未逐帧审核整段视频；九宫格只代表抽样帧。
- 未提供经核验的收益、成本节约比例或转化提升数据。

详见 [来源与验证记录](docs/provenance.md)。
